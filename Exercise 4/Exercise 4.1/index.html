Exercise 4.1 – SVG House & Garden

Demonstrating all SVG shape primitives, the <g> group element, and the SVG coordinate system.

SVG Coordinate System & Shape Annotations

SVG uses a top-left origin (0, 0). The x-axis increases to the right and the y-axis increases downward (opposite to the typical math convention). Each diagram below isolates one shape type and visually labels how its attributes map to positions on the canvas.

1. <rect> — Rectangle (House Body)

House body. x, y sets the top-left corner. The shape extends width px right and height px down.

2. <circle> — Circle (Sun)

Sun. Defined by its centre (cx, cy) and r (radius). The circle extends r pixels in every direction from the centre.

3. <ellipse> — Ellipse (Cloud)

Cloud. Like <circle> but with two radii: rx (horizontal) and ry (vertical). A larger rx produces a wide, flat shape.

4. <line> — Line (Sun Ray)

Sun ray. Defined by two endpoints: (x1, y1) start and (x2, y2) end. The browser draws a straight segment between them.

5. <polygon> — Polygon (Roof)

Roof. Defined by a list of points (vertices). Unlike <polyline>, a polygon is automatically closed — the browser connects the last vertex back to the first.

6. <polyline> — Polyline (Flower-bed Fence)

Flower-bed fence. A series of connected line segments. Alternating y-values create the zig-zag. Unlike <polygon>, the shape is not automatically closed.

7. <path> — Path with Bézier Curves (Garden Path)

Garden path. M moves to the start. Each Q command takes a control point (purple — pulls the curve sideways) and an end point (blue/green — destination). Dashed lines show how control points influence the curve.

8. <text> — Text (Label)

Label. x, y sets the anchor/baseline point. text-anchor="middle" horizontally centres the text around that x. The y value defines the text baseline, not the top.

9. <g> — Group Element with translate (Windows)

Grouped windows. The outer <g> applies shared fill and stroke to both windows. Each inner <g> uses translate(x, y) to shift its local origin (blue dashed axes) to the desired canvas position. Shapes inside use local coordinates starting at (0, 0).
