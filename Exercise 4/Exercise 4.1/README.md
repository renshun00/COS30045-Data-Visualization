# Exercise 4.1 – SVG Shapes: House & Garden

## Overview

This exercise demonstrates the use of **SVG primitives** (shapes) to create a picture of a house and garden. The page includes:

- An SVG scene using all shape types: `<rect>`, `<circle>`, `<ellipse>`, `<line>`, `<polygon>`, `<polyline>`, `<path>`, and `<text>`
- Annotated explanations of the **SVG coordinate system** for each shape
- A `<g>` (group) element to apply shared styling to both windows, positioned using `transform="translate(x, y)"`

## Files

- **index.html** – The main webpage containing the SVG picture and coordinate annotations
